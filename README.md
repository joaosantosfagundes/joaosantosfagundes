## 📌 Como ativar a cobrinha (`contribution_snake`)

1. No repositório `joaosantosfagundes/joaosantosfagundes`, vá em **Actions** → **New workflow** → **set up a workflow yourself**.
2. Cole o conteúdo abaixo e salve como `.github/workflows/snake.yml`:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 0 * * *"
  push:
    branches:
      - main
  workflow_dispatch: {}

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-only@v3
        with:
          github_user_name: joaosantosfagundes
          outputs: |
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

3. Rode o workflow manualmente uma vez (`Run workflow`) para gerar a branch `output`.
4. Pronto — a imagem do README passa a puxar direto dessa branch.
